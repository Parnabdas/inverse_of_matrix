Matrix Inverse Explorer

Find the inverse of a square matrix step by step. Every number is an exact fraction, never a decimal.

A⁻¹ = adj(A) ÷ det(A)
📖 Little glossary
Square matrix
A grid with the same number of rows and columns (2×2, 3×3, ...).
Determinant, det(A)
One number computed from the matrix. If it is 0, the matrix has no inverse.
Minor, Mᵢⱼ
Cover row i and column j, then take the determinant of what is left.
Cofactor, Cᵢⱼ
The minor with a sign: Cᵢⱼ = (−1)i+j × Mᵢⱼ.
Adjoint, adj(A)
The transpose of the cofactor matrix (rows become columns).
Inverse, A⁻¹
The matrix that undoes A: A × A⁻¹ = I (the identity matrix).
Singular matrix
A matrix with det(A) = 0. It has no inverse.
